# To-Do Login App

A Flask-based web application with user registration, login authentication, password hashing, sessions, and SQLite database integration.

## Features
- User registration
- Login validation
- Password hashing
- Session-based login/logout
- SQLite database integration
- Dynamic HTML templates

## Technologies Used
- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- Git & GitHub

## What I Learned
This project helped me understand how backend authentication works, how user data is stored securely, how Flask routes connect with HTML templates, and how databases work inside a web application.
